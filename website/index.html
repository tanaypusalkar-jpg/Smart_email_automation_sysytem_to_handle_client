What's actually under the hood

      

        

          
API layer

          
FastAPI. Two routers — emails and compose — each with one job. Pydantic models validate every request and response.

        

        

          
Claude service

          
Every prompt lives in one file. JSON-only responses, retried with exponential backoff, parsed defensively against markdown fences Claude sometimes adds anyway.

        

        

          
RAG layer

          
A ChromaDB collection stores past templates. New drafts query it for the closest matches before Claude writes a word — real similarity search, not a hardcoded lookup.

        

        

          
Audit log

          
A SQLite database (SQLAlchemy) logs every classify, compose, and send call — queryable at /logs.

        

        

          
Access control

          
Sending mail is rate-limited per IP and gated behind Google OAuth once configured — off by default so local dev stays frictionless.

        

        

          
Delivery

          
SMTP via aiosmtplib. A DRY_RUN flag means you can exercise the entire pipeline, including "sending," without a single real email leaving the building.
